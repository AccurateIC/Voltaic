
# Frontend - React 19 SPA

Generator set monitoring dashboard with real-time data visualization.

## Quick Start

```bash
# Install dependencies (from monorepo root)
pnpm install

# Start development server
pnpm --filter frontend run dev
```

**App:** http://localhost:3000

## Key Commands

```bash
pnpm --filter frontend run dev      # Development server
pnpm --filter frontend run build    # Production build
pnpm --filter frontend run preview  # Preview production build
```

## Tech Stack

- **React 19** with hooks and React Compiler
- **Vite** for fast development and building
- **TailwindCSS + DaisyUI** for styling
- **React Query** for server state management
- **React Router 7** for client-side routing
- **Tuyau Client** for type-safe API calls
- **Chart.js** for data visualization
